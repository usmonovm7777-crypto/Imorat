# Сервер Imorat Go (API)

Бэкенд маркетплейса: вход по SMS / Google / Apple, каталог, заказы с серверным расчётом цен и остатков,
доставка Яндекс, Usta AI, регистрация магазинов с модерацией и кабинет продавца.

- **Без сторонних библиотек**: нужен только Node.js 22.13+ (встроенные `node:http`, `node:sqlite`, `crypto`).
- **База** — один файл SQLite (`data/imorat.db`); при первом запуске заполняется из `data/catalog.json` (9 магазинов, 347 товаров).
- **Работает без ключей** в тестовом режиме: SMS-код показывается на сайте, доставка считается по тарифам, Usta AI отвечает офлайн.

## Запуск на компьютере

```bash
cd server
cp .env.example .env      # впишите JWT_SECRET и ADMIN_PHONES
npm start                 # http://localhost:8787/api/health
npm test                  # автотесты API
```

Чтобы сайт работал с этим сервером, в файле `config.js` в корне сайта укажите адрес:
`window.IMORAT_API = "http://localhost:8787";`

## Запуск в интернете (VPS + Docker)

1. Арендуйте VPS с Ubuntu (1 ГБ памяти достаточно) и установите Docker.
2. Направьте домен, например `api.imorat.uz`, на IP сервера (A-запись в DNS).
3. На сервере:
   ```bash
   git clone https://github.com/usmonovm7777-crypto/Imorat Go.git && cd Imorat Go/server
   cp .env.example .env && nano .env     # API_DOMAIN, PUBLIC_URL, JWT_SECRET, ADMIN_PHONES, ключи
   docker compose up -d --build
   ```
   Caddy сам получит HTTPS-сертификат. Данные хранятся в Docker-томе `imorat-data`.
4. В `config.js` сайта: `window.IMORAT_API = "https://api.imorat.uz";` — и запушить на GitHub.

Резервная копия базы: `docker compose exec api sh -c "cp /data/imorat.db /data/backup-$(date +%F).db"`.

## Ключи (всё необязательно, подключайте по мере готовности)

| Что | Переменные | Где взять |
|---|---|---|
| SMS-коды | `ESKIZ_EMAIL`, `ESKIZ_PASSWORD`, `SMS_TEMPLATE` | Кабинет eskiz.uz; текст SMS должен совпадать с одобренным шаблоном |
| Вход через Google | `GOOGLE_CLIENT_ID` | Google Cloud Console → Credentials → OAuth client (Web), добавить домен сайта |
| Вход через Apple | `APPLE_CLIENT_ID`, `APPLE_REDIRECT_URI` | Apple Developer → Services ID с Sign in with Apple |
| Usta AI | `ANTHROPIC_API_KEY` | console.anthropic.com |
| Цены Яндекс Доставки | `YANDEX_DELIVERY_TOKEN` | Бизнес-аккаунт Яндекс Доставки → API-токен |

Модераторы магазинов — номера в `ADMIN_PHONES`: после входа на сайт они видят блок «Модерация магазинов» в кабинете продавца.

## API кратко

| Метод | Путь | Что делает |
|---|---|---|
| GET | `/api/config` | какие сервисы подключены |
| POST | `/api/auth/otp/send`, `/api/auth/otp/verify` | вход по SMS (5 мин, 5 попыток, повтор через 60 с) |
| POST | `/api/auth/google`, `/api/auth/apple` | проверка ID-токена; новый аккаунт подтверждает телефон |
| GET/PATCH | `/api/me` | профиль: имя, район, роль покупатель/прораб |
| GET | `/api/catalog` | магазины, товары, цены и остатки (ETag, gzip) |
| POST | `/api/quote` | расчёт корзины: опт, комплекты, промокод, доставка |
| POST | `/api/orders` | заказ: проверка остатков, списание, разбивка по магазинам |
| GET | `/api/orders`, `/api/orders/:num` | заказы и статусы доставки |
| POST | `/api/ai/chat` | Usta AI (потоковый ответ, лимиты в день) |
| POST/PATCH | `/api/seller/store` | анкета магазина: описание, категории, телефон, часы, адрес, геоточка |
| GET | `/api/seller/summary` | кабинет: заказы, выручка, товары |
| PATCH/POST | `/api/seller/offers…`, `/api/seller/products…` | цены, остатки, новые товары, фото |
| PATCH | `/api/seller/shipments/:id` | сборка → курьер → доставлен |
| GET/PATCH | `/api/admin/stores…` | модерация магазинов |
| POST | `/api/seller/import` | загрузка прайса: много цен и остатков сразу, новые товары |
| GET | `/api/seller/stats` | статистика продавца: просмотры, корзины, заказы, цены против рынка |
| POST | `/api/events` | анонимные счётчики просмотров и добавлений в корзину |
| GET/POST | `/api/masters…` | мастера: список, профиль, анкета, заявки, отзывы |
| GET/POST | `/api/me/bonus…` | бонусы: баланс, история, код друга |
| GET/PATCH | `/api/admin/masters…` | модерация мастеров |
| GET/POST | `/api/admin/channel…` | Telegram-канал: превью и «опубликовать сейчас» |

## Заказы, уведомления, деньги
- **Сроки для магазина:** напоминание через 5 минут, SMS через 10, автоотмена через 20 минут без ответа; передать заказ — 4 часа.
  Ночью таймер ждёт открытия магазина (часы работы — время Ташкента).
- **Telegram-бот @imoratGo_bot** (`TELEGRAM_BOT_TOKEN`), меню на русском и узбекском:
  - **все:** поиск товаров обычными словами (опечатки, латиница, синонимы) с ценами и ссылками на карточки;
    мастера по специальностям и заявка в три шага (описание → когда → район); «Мои заказы», «Бонусы», код для друзей;
    вход кнопкой «Поделиться номером» (Telegram подтверждает номер; новый номер = новый аккаунт).
  - **мастера:** заявка приходит с кнопками «Принять» / «Не смогу» / «Работа выполнена», клиент сразу получает номер
    мастера; «Мои заявки»; «Пауза для заявок» прячет анкету из списка. После работы клиент ставит звёзды и пишет отзыв в боте.
  - **магазины:** «Подключить Telegram» в кабинете → заказы с кнопками «Принять», «Нет в наличии», «Готов».
  - ссылки с сайта: `?q=цемент` открывает результаты поиска, `?ai=вопрос` — Usta AI.
- **Push-уведомления** на телефон для сайта-приложения (PWA): ключи VAPID создаются автоматически.
- **Рейтинг магазина:** % выполненных заказов, среднее время принятия, отзывы покупателей (1–5 звёзд), ответ магазина.
- **Финансы:** комиссия по категориям (`COMMISSION`) считается с выполненных заказов. Пока покупатели платят магазину
  напрямую, комиссия — долг магазина; модератор отмечает полученные платежи в разделе «Финансы Imorat Go».

- **Бонусы:** кешбэк 1% (мастерам и прорабам 2%) после получения заказа, оплата бонусами до 20% товаров,
  возврат бонусов при отмене. Код друга: другу 30 000 сразу, пригласившему 30 000 после первого заказа друга (`BONUS_*`).
- **Мастера:** анкету проверяет модератор; заявка уходит мастеру в кабинет и Telegram, номер мастера покупатель видит
  после принятия заявки; после работы — оценка.
- **Telegram-канал** (`TELEGRAM_CHANNEL`, бот — администратор канала): каждый день в `CHANNEL_HOUR` товар дня с фото,
  новинки и снижения цен от 5%, новые магазины — сразу после одобрения.

## Нагрузка
Проверено нагрузочным тестом (`node tools/loadtest.mjs server`, затем `node tools/loadtest.mjs client`):
на машине с 2 ядрами один процесс сервера держит около 10 000 запросов в секунду; при 500 одновременных
покупателях 95% ответов быстрее 75 мс, без ошибок сервера. Каталог собирается один раз и хранится в памяти
(пересборка при изменении цен и раз в минуту для рейтингов). Сам сайт — статические файлы (GitHub Pages /
Cloudflare), их нагрузка не ограничена. Узкие места — внешние сервисы: Usta AI (лимиты в день на человека),
SMS и Яндекс. При сотнях тысяч заказов в день базу можно перенести с SQLite на PostgreSQL.

## Защита
- Модераторы входят по SMS **и** коду из приложения-аутентификатора (`ADMIN_MFA=1`), сессия модератора — 12 часов.
- Журнал действий модераторов (`GET /api/admin/audit`), «Выйти на всех устройствах» для любого пользователя.
- Резервная копия базы каждый день в `BACKUP_DIR` (хранится 14 дней). Копируйте её и за пределы сервера.
- Тревоги в Telegram модераторам: ошибки сервера, новые магазины на проверке, сбой резервной копии.
- Рекомендуется Cloudflare перед `api`-доменом и SSH только по ключу.
