Imorat Go — фирменный знак (brand kit)

Как писать название: в тексте — «Imorat Go» (обе части с большой буквы), в логотипе — «imorat go».

Цвета
  Бирюзовый (основной)   #0B6E69   — тёмная версия на тёмном фоне: #3DB3AA
  Оранжевый (акцент)     #D9530A   — на тёмном фоне: #FF8040
  Чёрный текст           #131B1A
  Светлый фон            #F3F5F2
Шрифт надписи: Inter Display Black (буквы в логотипе уже переведены в кривые — шрифт не нужен).

Папки
  logo/      imorat-go-logo        — основной, на светлом фоне (SVG и PNG 2000 px)
             imorat-go-logo-dark   — для тёмного фона
             imorat-go-logo-white  — полностью белый, для бирюзового фона и фото
             imorat-go-logo-mono   — одноцветный чёрный: печать, штампы, факс, гравировка
             imorat-go-logo-stacked— вертикальный: аватарки, визитки, наклейки
             imorat-go-mark        — только знак без надписи
  icons/     иконки сайта и приложения: favicon.ico, 16–1024 px, maskable-512 (Android), apple-touch-icon (iPhone)
  telegram/  аватарка бота @imoratGo_bot и канала @imoratgo (640×640), светлая и тёмная
  social/    og-image.png 1200×630 — картинка, которая показывается при отправке ссылки на сайт в Telegram, WhatsApp, Facebook
  app/       файлы для сборки мобильного приложения (Capacitor): иконка, фон, заставка

Правила
  • Вокруг логотипа оставляйте свободное поле не меньше высоты буквы «о».
  • Минимальный размер надписи — 24 px по высоте; меньше — используйте только знак.
  • Не растягивайте, не меняйте цвета и не ставьте надпись на пёстрые фото — для фото есть белая версия.
