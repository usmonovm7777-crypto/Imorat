Qurilish Go — фирменный знак (brand kit)

Как писать название: в тексте — «Qurilish Go» (обе части с большой буквы), в логотипе — «qurilish go».

Знак: четыре скруглённые плитки — дом, мастерок, строительная каска, кирпичи (оранжевые градиенты, белые рисунки).
Цвета
  Оранжевый (основной)   #B8480A   — на тёмном фоне: #FF8A3D
  Плитки знака           #FFA126→#F2520D, #EE4A1C→#C4260F, #FFBE73→#F27A2E, #F7861F→#D63D0E
  Текст                  #1B1917   — на тёмном фоне: #F6F1EB
  Светлый фон            #F6F4F0   — тёмный фон: #1D1A17
Шрифт надписи: Inter Display Black.

Файлы
  qurilish-go-mark.svg        — только знак (вектор)
  qurilish-go-logo.png        — знак + надпись, на светлом фоне (прозрачный PNG 2000 px)
  qurilish-go-logo-dark.png   — для тёмного фона
  ../icons/                   — иконки сайта и приложения (favicon, 192/512/1024, maskable, apple-touch), картинка для соцсетей og-image
  ../app/assets/              — исходники иконки и заставки приложения (Capacitor Assets)
