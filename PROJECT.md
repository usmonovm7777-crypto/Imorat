# Imorat Go — память проекта (для разработчиков и AI-ассистентов)

Один файл о том, как устроен проект, где что лежит и какие решения уже приняты. Обновляйте при крупных изменениях.

## Что это
Маркетплейс строительных магазинов Ташкента: каталог с ценами и остатками магазинов, доставка Яндекс, Usta AI
(подбор материалов), 3D-дизайнер комнат, мастера, Telegram-бот `@imoratGo_bot`, канал `@imoratgo`.
Языки: русский, узбекский (новая латиница ö ğ ş ç), английский. Бренд: в тексте **Imorat Go**, в логотипе **imorat go**.
Цвета: teal `#0B6E69`, orange `#D9530A`, ink `#131B1A`, paper `#F3F5F2`.

## Как устроен клиент (`src/page.html`)
- Тексты: `L(ru, uz, en)`. Узбекский в исходнике может быть в старой орфографии — `uzNew()` переводит на выходе.
  Английский берётся из словаря `EN[ru]` (ключ — точный русский текст); шаблонные строки передают английский третьим аргументом.
  Новый текст: добавьте пару `L("…", "…")` **и** ключ в `EN` (иначе в EN покажется русский). Словарь собирается
  скриптами из `scratchpad/agents/en` (extract.py / merge.py) — при отсутствии просто добавьте ключ в объект `EN` вручную.
- Числа: `fmt`/`fmtN` (разряды по языку), десятичный разделитель `DEC`, локаль дат `LOCALE` — меняются в `syncLangFormats()`.
- Режимы: `API` пуст → демо (localStorage); `API` задан → `apiBoot()` → `/api/config` → `syncCatalog()`.
  `preLaunch()` (сервер подключён, товаров < 12) → главная «Скоро открытие» (`renderHomeLaunch`).
- Поиск: `smartSearch()` — транслит, стемминг, синонимы `SK_SYN`, опечатки (Дамерау-Левенштейн); индекс включает ru/uz/en.
- Дизайнер: `DS` состояние, `dsEstimate()` смета, фото-режим — WebGL2 SDF-шейдер `DS_PHOTO_FS` (`dsPhoto*`).
- Эффекты (`html.fx`, только компьютер с мышью или «Эффекты: вкл»): всё, что движется каждый кадр, двигается через `transform`/`opacity`
  на отдельном элементе — свечение героя `.hero-glow`, подсветка карточки `.glow` (создаётся при наведении), бегущая рамка `.askbar::before`,
  курьер на карте `.truckel` (`offset-path`, пауза вне экрана через IntersectionObserver). Движения мыши сводятся к одному обновлению на кадр
  (`pointerFrame`). Не возвращайте SMIL `animateMotion`, `filter: blur` в анимациях и `will-change` на всех карточках: это и было причиной
  рывков в Safari. Мерить: `scratchpad/perf/measure2.js`, `trace2.js`, `idle.js` (Chromium, троттлинг CPU 4×).
- Роутер: `route = { view, cat, … }`, хэш `#catalog`, `#cat-<id>`, `#p-<id>`, `#design`, `#masters`, `#seller`, `#store-<id>`, `?lang=en`, `?q=`.

## Как устроен сервер
- `.env` — см. `server/.env.example`. В проде сервер не стартует с SMS в dev-режиме (`ALLOW_DEV_SMS=1` только на тесте).
- `DEMO_STORES=0` — без 9 демо-магазинов (реальный запуск); `dropDemoStores()` удаляет их из существующей базы.
- Роли: покупатель / `pro` / продавец (`store_id`) / админ (`ADMIN_PHONES` + TOTP). `needSeller` блокирует магазины `blocked/rejected`;
  `pending` может готовить товары — они скрыты до одобрения (каталог берёт офферы только магазинов `active`).
- Бонусы: кешбэк 1 % (2 % pro), потолок `BONUS_MAX_CASHBACK` за отправление, не начисляется владельцу на свой магазин;
  приветственный и реферальный бонусы — после **первой доставки** друга; лимит приглашений `BONUS_MAX_INVITES`/мес.
- Лимиты: OTP по IP щедро (CGNAT), строго по номеру; импорт прайса 20/сутки, новых товаров 500/сутки, фото 100/сутки на магазин.
- Комиссия: `COMMISSION=build:4,metal:4,fasten:4,*:8`; считается с выполненных заказов, отчёт в кабинете.
- Оплата картой (`payments.js`): Payme Merchant API (JSON-RPC `/api/pay/payme`) и Click SHOP API (`/api/pay/click`). Онлайн-заказ создаётся
  с отправлениями `unpaid` (магазин их не видит), после callback «оплачено» → `new` + уведомления; не оплаченные за `PAY_TIMEOUT_MIN`
  отменяются в `sweep`. Отмена оплаченного отправления → `pay_status=refund_due` и сообщение админам (возврат пока вручную в кабинете провайдера).
  Финансы магазина: `balance = вся комиссия + доставка, полученная магазином с покупателей (store/cash) − деньги за товар по картовым заказам,
  которые держит Imorat Go (`online_held`) − расчёты`; `payout_due` = доля магазина (товар − комиссия) по картовым заказам, включая заказы
  со статусом `refund_due` (другой магазин отменил свою часть). Админ может пометить заказ «оплачен» вручную — это запускает `orderPaid()`.

## Тесты
- Сервер: `cd server && npm test`.
- Браузер: Playwright-скрипты в scratchpad (`t/*.js`): `qa.js` (все режимы/языки/темы), `e2e2.js` (полный путь с API),
  `ds*.js` (дизайнер), `shop.js`, `ms.js`, `en_smoke.js`. Локальные серверы: 8090 исходник, 8091 сборка, 8080 сборка + API 8787,
  8081 сборка + API 8788 в режиме запуска, 8799 мок-AI.

## Принятые решения
- Один файл сайта без сборщика и фреймворков — чтобы работать с GitHub Pages, в WebView и офлайн.
- Сервер без зависимостей — один `node` и один файл SQLite; бэкапы — копия файла.
- Цены всегда считает сервер (`/api/quote`), клиент только показывает.
- Доставка оплачивается только картой на сайте (одна сумма за товар и доставку); наличные — только при самовывозе. Рассрочки нет.
  Пока ключей Payme/Click нет, покупатель платит магазину при получении.
- Английские термины: «мастера» → *Pros*, «виджеты» → *Widgets*, валюта *UZS*.
