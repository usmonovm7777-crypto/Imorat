# Приложение Imorat (Android и iPhone)

Приложение собирается **из того же сайта** с помощью Capacitor: один код, одинаковый каталог, корзина,
заказы, кабинет продавца и Usta AI. Анимации на телефоне спокойные (как на мобильной версии сайта).

## Три способа поставить Imorat на телефон

| Способ | Как | Когда |
|---|---|---|
| **Приложение из сайта (PWA)** | Открыть сайт → ☰ → «Приложение Imorat» → «Установить» (iPhone: «Поделиться» → «На экран Домой») | Уже сейчас, бесплатно. Есть уведомления о заказах |
| **Android-файл APK** | GitHub → Releases → **app-latest** → скачать `Imorat.apk` на телефон → установить (разрешить установку из этого источника) | Собирается автоматически после каждого обновления сайта |
| **Google Play / App Store** | Публикация через аккаунты разработчика | После пилота с магазинами |

## Автосборка APK
Файл `.github/workflows/android.yml`: при каждом обновлении сайта GitHub сам собирает APK и выкладывает его
в релиз **app-latest**. Запустить вручную: GitHub → Actions → «Android app (APK)» → **Run workflow**.

## Сборка у себя
```bash
cd app
npm install
npm run android     # откроет Android Studio
npm run ios         # только на Mac с Xcode
```
Адрес сервера берётся из `../config.js` или из переменной `IMORAT_API`.

## Публикация в магазинах
**Google Play** (разово $25): аккаунт Google Play Console → подписанная сборка AAB (для неё создаём ключ подписи и
добавляем его в секреты GitHub — сделаю, когда будет аккаунт) → карточка приложения, скриншоты, политика
конфиденциальности → проверка обычно несколько дней.

**App Store** ($99 в год): нужен Apple Developer и сборка в Xcode на Mac (или облачная сборка). Apple не любит
приложения, которые просто повторяют сайт, поэтому перед отправкой добавим нативные функции: push-уведомления,
съёмку фото товаров камерой в кабинете продавца, геолокацию для адреса доставки.

## Уведомления в приложении
Сейчас заказы и статусы приходят продавцам и покупателям через **Telegram-бота**. Нативные push-уведомления
(Firebase для Android, APNs для iPhone) подключим вместе с публикацией в магазинах — для них нужны аккаунты разработчика.
