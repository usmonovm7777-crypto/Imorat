# Qurilish Go — свой домен и сервер за один вечер

Инструкция для владельца без технической подготовки. Результат: сайт открывается по адресу `https://imorat.uz`,
сервер (заказы, оплата, бот) — по `https://api.imorat.uz`, всё с HTTPS, резервными копиями и одной командой `imorat`
для управления. Если что-то не получается — пришлите мне вывод команды `imorat doctor`, по нему всё видно.

Почему сервер в Узбекистане: персональные данные покупателей хранятся в стране (так спокойнее с законом о персональных данных —
юрист подтвердит), трафик идёт по TAS-IX (быстро и дёшево для абонентов), Payme и Click без проблем достучатся до сервера.
Минимум памяти — 1 ГБ хватает, но 2 ГБ оставляют запас на рост.

При заказе VPS выберите **Ubuntu 24.04** (или 22.04) и способ входа «по паролю root» или по SSH-ключу — провайдер пришлёт IP-адрес
сервера и пароль.

## 1. Создайте Telegram-бота (2 минуты, до установки)

Пока нет договора с Eskiz на SMS, вход на сайт идёт через Telegram: бот просит поделиться контактом — это и есть подтверждение номера.
1. В Telegram откройте `@BotFather` → `/newbot` → имя «Qurilish Go» → username `imoratGo_bot` (если занят — любой с `bot` на конце).
2. BotFather пришлёт **токен** вида `1234567890:AAE…` — скопируйте его, он понадобится на шаге 3. Никому не показывайте.
3. Там же: `/setdescription` — «Строительные магазины Ташкента: заказы, доставка, вход на сайт».

## 2. DNS — три записи у регистратора

В панели домена (раздел DNS) добавьте три записи типа **A**, все на IP-адрес вашего сервера:

| Имя | Тип | Значение |
|---|---|---|
| `@` (или пусто — сам imorat.uz) | A | IP сервера |
| `www` | A | IP сервера |
| `api` | A | IP сервера |

Записи вступают в силу от 5 минут до часа. Установку можно начинать сразу — сертификаты HTTPS появятся сами, как только DNS заработает.

## 3. Установка — одна команда

Подключитесь к серверу (на Windows — программа PuTTY или встроенный терминал, на Mac — «Терминал»):

```bash
ssh root@IP_СЕРВЕРА
```

И выполните (подставьте свой домен, телефон и токен бота):

```bash
curl -fsSL https://raw.githubusercontent.com/usmonovm7777-crypto/Imorat/main/server/tools/install.sh -o install.sh
sudo bash install.sh --site imorat.uz --admin 998901234567 --bot 1234567890:AAE... --owner umv_721-login
```

`--owner` — ваш логин для входа в панель по паролю (кроме входа по телефону). В конце установки скрипт спросит пароль
(не короче 10 символов) и сохранит в `.env` только его хеш; сам пароль нигде не хранится. Потом поменять: `imorat owner`.

Скрипт за 3–5 минут: ставит Docker, скачивает код в `/opt/imorat`, создаёт настройки `server/.env` со случайным секретом,
включает файрвол (открыты только SSH, 80 и 443) и автоматические обновления безопасности Ubuntu, запускает сервер и сайт,
ставит команду `imorat`, ночные резервные копии и автообновление с GitHub каждые 10 минут (сайт — всегда, сервер — когда менялся его код).
Повторный запуск безопасен: существующие настройки и база сохраняются.

Проверка:

```bash
imorat doctor
```

Все строки должны быть с ✓. Крестики у DNS — подождите и повторите; крестик у HTTPS — обычно тоже DNS, посмотрите `imorat logs caddy`.

## Этап 0 — запуск без юрлица и договоров (так сервер работает сразу после установки)

Пока нет договоров с Payme/Click, Eskiz и Яндекс Доставкой, сервер работает в режиме «оплата при получении»
(`ALLOW_PAY_AT_STORE=1`, ключей платёжек нет — установщик так и настраивает):

- **покупатель платит магазину напрямую** при получении — наличными или переводом; Qurilish Go деньги не принимает и
  комиссию не удерживает (в кабинете продавца и в анкете так и написано);
- **доставку делает сам магазин** своим курьером: сайт показывает, какая машина понадобится, а цену доставки магазин
  называет покупателю при подтверждении заказа — сайт её не выдумывает и в итог не включает; есть самовывоз;
- **вход только через Telegram-бота** (без SMS-договора), заказы продавцу приходят в бот с кнопками «Принять» →
  «Курьер выехал» → «Доставлен»;
- комиссия, эквайринг, бесплатные месяцы, Яндекс и карты включаются позже ключами из раздела 5 — ничего переустанавливать
  не нужно. Как только появятся ключи Payme/Click, оплата картой включится сама, а оплата при получении останется только
  для самовывоза (`ALLOW_PAY_AT_STORE=0` — если нужен сайт только с картами).

Что нужно купить и сделать физлицу: домен (раздел 2), VPS (раздел 0), бот (раздел 1) — и всё.

## 4. Первый вход

1. Откройте `https://imorat.uz` → «Профиль» → «Войти через Telegram» → в боте «Start», «Поделиться контактом» и «✅ Да, это я — войти».
   Номер из `--admin` становится модератором. Либо откройте `https://imorat.uz/#owner` и войдите логином из `--owner` и своим паролем —
   это тот же владелец, со всеми правами.
2. Откройте `#seller` (Кабинет продавца) → раздел «Защита входа модератора» → отсканируйте QR в Google Authenticator / 1Password
   и введите код. Без двухэтапного кода админка закрыта — это защита от чужого входа.
3. Зарегистрируйте первый магазин (можно свой тестовый), загрузите шаблон прайса, одобрите магазин в блоке «Модерация».
   У нового магазина первые 3 месяца комиссия Qurilish Go 0% — срок виден в админке, кнопкой «0% +3 мес» его можно продлить.

## 5. Ключи — подключайте по мере получения

Команда `imorat env` открывает настройки в редакторе (стрелки — перемещение, `Ctrl+O` Enter — сохранить, `Ctrl+X` — выйти)
и сама перезапускает сервер.

| Что даёт | Строки в `.env` | Где взять | Срок |
|---|---|---|---|
| **Оплата картой** — до неё работает этап 0: оплата при получении магазину | `PAYME_MERCHANT_ID`, `PAYME_KEY`; `CLICK_SERVICE_ID`, `CLICK_MERCHANT_ID`, `CLICK_SECRET_KEY` | договоры с Payme (business.payme.uz) и Click (click.uz/business); нужно юрлицо или ИП с расчётным счётом. В их кабинетах укажите адреса уведомлений: `https://api.imorat.uz/api/pay/payme` и `https://api.imorat.uz/api/pay/click` | 1–2 недели — начинайте первым |
| SMS-коды входа (вместо входа только через Telegram) | `ESKIZ_EMAIL`, `ESKIZ_PASSWORD`, `SMS_TEMPLATE`; удалите строку `SMS_MODE=telegram` | eskiz.uz — договор и согласование текста SMS | ≈ неделя |
| Яндекс Доставка: точные цены, автоматический вызов курьера, курьер на карте у покупателя | `YANDEX_DELIVERY_TOKEN` | бизнес-кабинет Яндекс Доставки (API Claims), договор на юрлицо | 1–2 недели |
| Настоящая Яндекс Карта и подсказки адресов при оформлении | `YANDEX_MAPS_KEY` | developer.tech.yandex.ru → ключ «JavaScript API и HTTP Геокодер» (стартовый тариф бесплатный) | 1 день |
| Usta AI, фото-поиск, AI-дизайнер | `ANTHROPIC_API_KEY` | console.anthropic.com → API keys, пополнить баланс от $5 | 10 минут |
| Канал с товаром дня | `TELEGRAM_CHANNEL=@imoratgo` и бот — администратор канала | Telegram | 5 минут |

До ключей Яндекса цены доставки считаются по тарифной формуле, а статусы ставит магазин; до ключа карт — карта OpenStreetMap.
Комиссия и бесплатные месяцы: `COMMISSION=*:1`, `ACQUIRING_PERCENT=2`, `PROMO_MONTHS=3`. Это единственное место, где задаются ставки: сайт и приложение берут их из `/api/config`. `ACQUIRING_PERCENT` — не наша ставка, а тариф банка: после подписания договора эквайринга впишите его сюда (`payme:2,click:1.8`, если тарифы разные).

## 6. Каждый день

| Команда | Что делает |
|---|---|
| `imorat status` | что запущено, отвечает ли API, место на диске, последние копии |
| `imorat logs` / `imorat logs caddy` | живой журнал (выход — `Ctrl+C`) |
| `imorat env` | изменить настройки и перезапустить |
| `imorat update` | обновить всё до последней версии с GitHub прямо сейчас (и так происходит само каждые 10 минут: сайт — всегда, сервер — когда менялся его код) |
| `imorat backup` | копия базы в `/var/backups/imorat` (ночью делается сама, хранится 30 штук; внутри контейнера — ещё 14 ежедневных) |
| `imorat restore ФАЙЛ` | вернуть копию базы |
| `imorat doctor` | диагностика: DNS, порты, HTTPS, настройки, ключи |

Раз в месяц полезно скачать свежую копию базы к себе: `scp root@IP_СЕРВЕРА:/var/backups/imorat/$(ls -t /var/backups/imorat | head -1) .`
(или через программу FileZilla/WinSCP из папки `/var/backups/imorat`).

## 7. Если что-то сломалось

- Сайт не открывается → `imorat doctor`. Чаще всего DNS ещё не обновился или сервер перезагружался — `imorat restart`.
- API «перезапускается по кругу» → `imorat logs api`: первая строка с `Error` говорит, какой настройки не хватает (например, `SMS is in dev mode` — не указан ни токен бота, ни Eskiz).
- Заказы не приходят в Telegram → бот должен быть запущен хотя бы раз владельцем магазина (`/start`), а токен — верным; проверьте `imorat logs api | grep -i telegram`.
- Оплата не проходит → в кабинете Payme/Click проверьте адреса callback и что сервер отвечает: `curl https://api.imorat.uz/api/health`.
- Закончилось место → `docker system prune -f` и `imorat status`.
- Перенос на другой сервер: новый сервер → установка той же командой → `imorat restore` с копией базы и папка `uploads` из `/var/backups/imorat`.

## Владелец и помощники

- **Владелец** — номер из `ADMIN_PHONES` и логин из `OWNER_LOGIN` (`imorat owner`): видит всё — обороты, финансы, выплаты, выписки,
  аудит, Telegram-канал — и управляет помощниками.
- **Помощник** — друг, который помогает с модерацией. Владелец создаёт его в «Панель Qurilish Go → Сотрудники»: логин и временный пароль
  (показывается один раз, передайте лично; при первом входе помощник обязан сменить его). Помощник видит модерацию магазинов и мастеров,
  жалобы и заказы; деньги, аналитику и список сотрудников — нет. Отключить можно в любой момент — его сессии закрываются сразу.
- Вход сотрудников: `https://imorat.uz/#owner` (или «Профиль → Вход для сотрудников»). 10 неверных паролей с одного адреса — пауза
  15 минут (считаются только неудачи, так что чужой перебор вашего логина вас не заблокирует).
  Двухэтапный код (приложение-аутентификатор) обязателен и для владельца, и для помощников, пока `ADMIN_MFA=1`.
- Пароль владельца меняется только на сервере: `sudo imorat owner` — после смены все ваши старые сессии закрываются, войдите
  заново. Пароль, который вы кому-то писали или диктовали, считайте
  раскрытым — поставьте другой.

## 8. Безопасность — что уже сделано и что помнить

Сделано установщиком: файрвол, автообновления Ubuntu, HTTPS, секрет сессий, права `600` на `.env`, двухэтапный код для модератора.
Помните: пароль root и токен бота никому не пересылать; если токен утёк — `@BotFather` → `/revoke` и `imorat env`;
для входа на сервер лучше завести SSH-ключ и выключить вход по паролю (провайдер обычно предлагает это при заказе).
