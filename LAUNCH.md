Короткая инструкция для владельца: что сделать, чтобы сайт, сервер и бот заработали «по-настоящему».
Подробности по серверу — в `server/README.md`, по приложению — в `app/README.md`.

## 2. Сервер за один вечер

```bash
# на VPS с Ubuntu (1 ГБ памяти хватит), Docker установлен, DNS api.<домен> → IP сервера
git clone https://github.com/usmonovm7777-crypto/Imorat.git && cd Imorat/server
cp .env.example .env && nano .env        # см. таблицу ключей ниже
docker compose up -d --build             # API + Caddy (HTTPS сам)
curl https://api.<домен>/api/health      # {"ok":true}
```

Потом в `config.js` сайта укажите `window.IMORAT_API = "https://api.<домен>";` и запушьте.

Обязательные переменные `.env`: `API_DOMAIN`, `PUBLIC_URL`, `JWT_SECRET` (`openssl rand -hex 32`), `ADMIN_PHONES`
(ваш номер — он модерирует магазины), `ALLOWED_ORIGINS` (адреса сайта), `DEMO_STORES=0` (без демо-магазинов).

В продакшене сервер **не запустится**, пока SMS в тестовом режиме (иначе коды входа видны всем): заполните
`ESKIZ_EMAIL`/`ESKIZ_PASSWORD` или на тестовом сервере поставьте `ALLOW_DEV_SMS=1`.

| Что даёт | Переменные | Где взять | Без ключа |
|---|---|---|---|

| Канал с товаром дня | `TELEGRAM_CHANNEL=@imoratgo` + бот админ канала | Telegram | постов нет |
| Usta AI, фото-поиск, AI-дизайнер | `ANTHROPIC_API_KEY` | console.anthropic.com | кнопки AI скрыты |

| Вход через Google / Apple | `GOOGLE_CLIENT_ID`, `APPLE_CLIENT_ID`, `APPLE_REDIRECT_URI` | Google Cloud Console / Apple Developer | только вход по SMS |

## 4. Первый день

1. Войдите на сайт своим номером (`ADMIN_PHONES`), включите двухфакторный код (приложение-аутентификатор) — без него админка закрыта.
2. Откройте `#seller` → зарегистрируйте первый магазин (можно свой тестовый), загрузите шаблон прайса, одобрите магазин в блоке «Модерация».
3. Проверьте путь покупателя: товар → корзина → заказ → в Telegram магазину приходит заказ с кнопками → статусы.
4. Подпишите с магазинами оферту (черновики договоров — в документе Claude «Договоры Imorat Go»).
5. Разошлите презентацию магазинам (RU/UZ), для партнёров и инвесторов — EN.

## 4а. Если сайт «тормозит» в Safari / на компьютере

Эффекты (параллакс, наклон карточек, бегущая рамка) включаются только на компьютере с мышью. Их можно выключить кнопкой «✦»
в шапке (запоминается в браузере). Все эффекты двигаются через GPU-трансформации и измерены под 4× замедлением процессора;
если на каком-то компьютере всё равно дёргается — сначала проверьте расширения браузера и «Снизить движение» в настройках ОС
(сайт его уважает и отключает анимации).

## 5. Пока каталог пуст

С `DEMO_STORES=0` сайт сам показывает «режим запуска»: главная «Скоро открытие», категории с пометкой «скоро»,
работают 3D-дизайнер, калькуляторы, мастера, кабинет продавца и Telegram-канал. Как только появится 12+ товаров,
главная переключится на обычный вид автоматически.

## 6. Резервные копии и обновления

- База — один файл SQLite в Docker-томе `imorat-data`; ежедневная копия пишется в `/data/backups` (переменная `BACKUP_DIR`).
- Снять копию вручную: `docker compose exec api sh -c "cp /data/imorat.db /data/backup-$(date +%F).db"`.
- Обновить сервер: `git pull && docker compose up -d --build`. Обновить сайт: пуш в `main` (GitHub Pages).
- Пересобрать сайт из исходника: `cp <исходник> src/page.html && python3 tools/build_site.py` (создаёт `index.html`, `sw.js`, SEO-страницы).

## 7. Что проверено перед запуском (октябрь 2026)

- 25 серверных автотестов, ~50 браузерных сценариев (Playwright, телефон и компьютер, RU/UZ/EN, светлая и тёмная темы).
- Аудит безопасности: исправлены самоначисление бонусов (потолок 200 000, без кешбэка на «свой» магазин, приветственный бонус
  после первого доставленного заказа), лимиты OTP по номеру, привязка Google/Apple только после подтверждения телефона,
  доступ заблокированных магазинов, смена владельца, лимиты импорта и фото, защита TOTP от повтора, CSP/X-Frame-Options, таймаут AI.
- Узбекские тексты вычитаны редактором (105 правок, единый новый алфавит ö ğ ş ç на сайте, в боте и SEO-страницах).
